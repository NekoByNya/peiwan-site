# 上线后第一周该做什么

部署成功 ≠ 能接到单。这份是**从"网站能打开"到"收到第一个预约"**的操作清单。

> 所有按钮名字都和后台实际界面对得上（我逐条核对过）。

---

## 一、上线当天（约 25 分钟，按顺序做）

### 1. 改管理密码（第一件事）

后台 →「安全与备份」→ 修改管理密码。

→ 环境变量里的密码只用于首次启动；改了之后，旧 Cookie 会立刻全部失效。

### 2. 开预约通知（不做这步，客户下单你不知道）

后台 →「安全与备份」→「预约通知」：

```
通知渠道：PushPlus（微信推送）
Token 或网址：微信扫码登录 pushplus.plus 后复制的 token（32 位字符）
```

点「保存通知设置」→ 再点「发送测试通知」。

→ 微信里收到「陪玩站测试通知」就成功了；下面那行会显示**上次发送结果**，
失败会写原因（比如 `HTTP 403` = token 不对、`超时` = 服务器连不上外网）。

> 不配置也能接单，只是**客户自己锁了时间你不会收到提醒**，得自己常看后台。

### 3. 设固定休息

后台 →「预约与时间」→ 固定休息规则 → 添加：

```
重复星期：全部勾上
开始 / 结束时间：02:00 到 10:00
备注：睡觉休息
```

→ 不加这条，你的时间表会显示**全天 24 小时都能约**，凌晨三点也可能有人下单。

### 4. 检查资料与报价

后台 →「资料与报价」，重点看三处：

| 字段 | 为什么重要 |
|---|---|
| 微信号 | 客户唯一的联系入口，写错等于没生意 |
| 陪玩报价 | 客户选"模式"时看到的就是它 |
| 服务说明 | 下面第三节列了客户最常问的问题，答案都在这里，写清楚能省掉一半聊天 |

### 5. 传 3 张展示墙

后台 →「展示墙」→ 建议顺序：

1. **游戏截图**（带战绩/撤离成功的那种，最好有你的 ID）
2. **游戏截图**（能体现你擅长的图，比如大坝/机密）
3. **老板评价**（让老客户发你一句，截图或直接文字）

→ 3 张就够开张了。空着的展示墙会让客户觉得"这人是不是不接单"。

> 🎬 **剪辑 / PS / 建站的作品**：传的时候在「点开跳转的链接（选填）」里填上成品地址
> （B 站视频用 `https://www.bilibili.com/video/BV…`，网站直接填 `https://…`）。
> 客户点那张图就**新窗口打开你的成品** —— 光有封面图，客户看不出来你做得好不好。
> 分类选「作品」（默认就有这一类；想加「剪辑作品」「建站作品」就去「分类管理」里加）。

### 6. 设置保活（不做这步，数据会丢）

免费实例 **15 分钟没人访问就休眠，一休眠 SQLite 和图片全清空**（Render 官方文档写明的）。

注册 <https://uptimerobot.com> → Add New Monitor → Type 选 `HTTP(s)` → URL 填：

```
https://你的服务名.onrender.com/api/ping
```

→ Interval 选 **5 minutes**。这个接口不查数据库、只回 35 字节，专门用来"叫醒"实例。

### 7. 跑一次体检

在电脑上执行：

```bat
python tests\check_deployed.py https://你的服务名.onrender.com
```

→ 26 项检查（页面 / 微信分享卡片 / 时间表接口 / 后台保护 / 静态资源 / 保活 / 速度 / HTTPS）。
看到 `通过 26 项 | 失败 0 项` 才算真的上线成功。

### 8. 手机微信里实测一遍

把网址发给你自己的小号，检查四件事：

- [ ] 分享卡片有**标题、简介和小图**（没有的话微信会缓存旧卡片，过一会儿或换个链接再试）
- [ ] 点「加微信」，能弹出复制成功或"长按文字复制"的框
- [ ] 进一个**陪玩**分区（`/z/xxx`）：选几个时间 → 点「下一步：选择模式」→ 出现模式卡片 + 「联系方式」下拉（微信 / 闲鱼 / QQ）
- [ ] 填个联系方式 → 点「立即锁定时间」→ 看到"时间已锁定 ✅"，同时**你手机上收到一条预约通知**；
      再回后台「预约与时间」看，那条会带「客户自助预约」徽章和**分区小标签**，模式、价格、联系方式、下单时间都在

> 想先自己试又不想留脏数据：试完在后台点那条记录的「取消」，那几格立刻恢复可预约。

> 客户也可以点弹窗里的「只复制文案，不锁定」——那条路不锁时间，文案里会写明"时间还没锁定"。

### 9. ★ 把包月客户录进「客户」档案（这一条最值钱）

后台 →「客户」→ 右上角「+ 新增客户」。手上的包月代肝，一个都别漏：

```
客户称呼：微信昵称（例如 小明）
联系方式：微信号
服务/分区：下拉选（例如 明日方舟）
买的档位：精托托管
金额    ：100R/月          ← 自由文本，你怎么写就怎么显示
开始日期：他下单那天
到期日期：★ 那天要提醒你的日子  ← 整个功能就靠这一格
```

→ 录完之后，「本周需要催的客户」那张清单就会在到期前一周把他顶上来。

**更快的路径**：如果客户已经在网站上自助预约过，去「预约与时间」找到那条记录，
右边点 **「存为客户」** —— 称呼、联系方式、渠道都帮你填好了，你只补档位和到期日。

> 一次性单子（散单陪玩、剪辑项目）**到期日期留空就行**，那种客户永远不会被催，
> 但档案留着，以后好查"这人上次买的是什么"。
>
> ⚠️ 别拖：**这个功能的价值 = 你录进去的客户数**。手里 5 个包月客户，
> 5 分钟就能录完；少录一个，就等着丢一个 600R/年。

## 二、发布：怎么让客户知道你有这个页面

**核心思路**：你发的不是广告，是"一个能自己看空档的页面"——它帮客户省事，所以不招人烦。

### 微信群 / 朋友圈（正式版）

> 做了个页面，能直接看我的空档时间，不用来回问"你几点有空"了：
> https://你的服务名.onrender.com
> 看中哪几格点一下、留个联系方式就锁上了，我这边马上收到消息；微信号也在页面里。

### 微信群 / 朋友圈（随意版）

> 现在我几点有空都能自己看了 👉 链接
> 不用再问我"在吗"，直接挑时间点下去，锁上我就来找你

### 闲鱼

商品描述里加一句：

> 具体空档时间看这里（实时更新）：https://你的服务名.onrender.com

### 发的时候注意

- **一次发一条**，别刷屏；群里发完就别反复顶
- 老客户可以**单独私聊**发，转化比群里高得多
- 朋友圈配一张**你自己最好的游戏截图**，比配链接预览更抓人

## 三、客户会问的问题（提前把答案写进「服务说明」）

| 客户会问 | 你的网站其实已经回答了 | 建议怎么写进「服务说明」 |
|---|---|---|
| 怎么算时间？ | 「以开第一局游戏为起点计时，时间打满」 | 保持默认那条，别删 |
| 怎么付钱？ | 网站不收款（故意的） | 加一条："微信/闲鱼先确认，开局前付或打完付都行" |
| 能不能改时间？ | 客户自己锁的格子，你可以在后台一键「取消」，格子立刻回到可预约 | 加一条："改时间提前 2 小时说一声，我放开格子" |
| 1 陪 2 要加钱吗？ | 「同一订单 1 陪 1 或 1 陪 2，不额外收取人数差价」 | 保持默认 |
| 玩什么图？ | 报价里的三档模式 | 在「打法标签」里把擅长的都写上 |
| 你靠谱吗？ | 「展示墙」 | 这是展示墙存在的唯一理由，别让它空着 |
| 点了预约就算约上了吗？ | 是的，**点了就锁定**，你也会收到通知 | 加一条："时间锁上后我会加你确认；临时有事提前说，我随时取消" |

## 四、每日 1 分钟 + 每周 10 分钟的例行

### 每天：开一次后台看客户（★ 最重要的一条习惯）

打开后台先看**标签栏上面那一条**，它把今天该干的事压成了一行：

```
📌 今天：3 单要打 · 2 个客户要催 · 1 单待确认
```

**三个数字都可以点**，点一下直接跳到要处理的那一块。

然后按这个顺序做（大约 1 分钟）：

```
① 点「N 单待确认」→ 跳到「预约与时间」最上面的待确认区
      · 加得上微信、谈得拢 → 点「已确认」
      · 联系不上 / 放你鸽子   → 点「释放时段」（会二次确认，客户不会收到通知）
      · 一条都没有时会显示「没有待确认的预约 ✓」
② 点「N 个客户要催」那一项 → 跳到「客户」页
      · 看「本周需要催的客户」→ 点「复制催续费话术」→ 切到微信粘贴发送
      · 客户说续，回来点「续费」
③ 都清完了，那一行会变成「今天没有待办，安心打单～」
```

**为什么要养成这个习惯**：陪玩按小时，客户自己会来找你；**代肝是包月的** ——
客户到期那天你要是不吱一声，他多半也不会主动说，单子就这么没了。
丢一个 50R/月的客户 = 一年 600R。**这 1 分钟就是这个页面存在的全部理由。**

**为什么还要看"待确认"**：客户在网站上点一下，那几格**立刻就锁走了**。
他要是没加微信、联系不上，那段时间就白占着 —— **时段就是你的库存，库存就是钱**。
所以每天顺手把那几条点掉：认下来的点「已确认」，联系不上的点「释放时段」还给别人。

> ⚠️ 别把待确认的单一直挂着。它就是靠"一直挂在你眼前"提醒你的，你要是习惯了无视它，
> 这个功能就白做了 —— 那几格本来可以卖给别人。

什么时候看：
- **早上起床刷手机时**顺手点开看一眼（30 秒）；
- **每周固定一天**（比如说周日晚上）认真过一遍「待催」清单。

卡片上的数字一变大，就说明有人快到期了 —— 你不需要记住任何日期。

### 每周 10 分钟

| 做什么 | 在哪 |
|---|---|
| **导出备份** | 后台「安全与备份」→ 下载备份 JSON（超过 7 天没导出，后台顶部会弹提醒） |
| **过一遍「客户」待催清单** | 后台「客户」→ 筛选「待催（超期+7天内）」→ 一个个发消息 |
| **录新客户** | 后台「客户」→「+ 新增客户」，或从「预约与时间」点「存为客户」 |
| **把不做的标成已结束** | 后台「客户」→ 那一行「编辑」→ 状态改「已结束」（别删，留着查账） |
| **★ 看一眼「收入」** | 后台「收入」→ 看大字（这个月比上月涨了还是跌了）+ 两个排行（哪个服务最来钱、哪个客户最舍得）+ 「近 3 个月」看趋势 |
| **★ 补记时间表外的单子** | 剪辑 / PS / 建站这类一次性单子 → 后台「收入」→ 右上角「+ 记一笔」（预约和续费会自动记，不用你管） |
| **看客户自助预约** | 后台顶部待办条的「N 单待确认」，或「预约与时间」最上面的待确认区 |
| **确认/释放预约** | 后台「预约与时间」→ 待确认区那两个按钮；已经确认过的要取消，去下面的时段列表点「取消」 |
| **检查自动释放设置** | 「预约与时间」→ 待确认区下面那行「待确认超过 [__] 小时自动释放（0 = 不自动）」（**建议先填 0**） |
| 看上周接了几单 | 后台「预约与时间」的统计卡 |
| **检查通知还通不通** | 后台「安全与备份」→「预约通知」→「发送测试通知」 |
| 更新展示墙 | 「展示墙」→ 传新截图 / 新评价 / **新作品（填上视频或网站链接）**，旧的可以「归档」 |
| 调整休息规则 | 「预约与时间」→ 固定休息规则（作息变了就改） |

> ★ **"看一眼收入"这条为什么要放进每周习惯**：陪玩的钱是"一单一单进来"的，
> 你每天都在收，但**月底回头想"我是不是该多推代肝"，光靠印象答不上来**。
> 每周花 3 分钟看两个排行，一个月后你就知道该把力气放在哪儿了 ——
> 这一页存在的唯一目的就是这个（**钱从哪来、该推什么**）。
>
> **你不用专门记账**：客户自助预约被你点「已确认」会自动记一笔，
> 续费时那个金额框默认就填好了。只有剪辑 / PS / 建站这种时间表外的单子要点一下「+ 记一笔」。

## 五、数据会告诉你的事

上线两三周后，回头看你的预约记录和收入，会有三个明显信号：

- **某几个时段总被约满** → 说明那是黄金时段，可以涨价，或者干脆少放几个格子（稀缺反而更好卖）
- **某些时段从来没人约** → 直接设成固定休息，少被打扰、也不用一直看手机
- **某个服务 / 某个客户在收入排行里一直靠前** → 下个月多推它：多传几张它的展示墙、
  朋友圈多发一条；那几个"最舍得"的客户，续费的时候多问一句、返图快一点
  （这套数字在后台「收入」标签页里，点「近 3 个月」看趋势最准）

## 六、什么时候该花钱升级（$7/月）

免费档能用，但这三种情况建议升级到 `0.5c-512mb` + 挂 1GB 持久磁盘（合计约 $7.25/月）：

1. **一周能接 10 单以上** —— 数据开始值钱了，别拿免费档赌（休眠就清空）
2. **有客户说"第一次打开等了好久"** —— 免费档休眠后要等约 1 分钟冷启动，很劝退
3. **你开始懒得导出备份了** —— 持久磁盘一挂，这件事就永久解决了

升级步骤在 [DEPLOY.md](DEPLOY.md) 的「最重要的一节」里。

## 七、出问题时的顺序

| 现象 | 先做什么 |
|---|---|
| 网站打不开 | 先在电脑上跑 `python tests\check_deployed.py 你的网址`，看哪一项失败 |
| 后台进不去 | 密码错了？或者换浏览器（Cookie 被禁会一直跳回登录页） |
| 数据不见了 | 大概率是休眠被清空了 → 后台「从备份恢复」把 JSON 导回去 → 然后赶紧设保活 |
| 时间表状态不对 | 检查「固定休息规则」是不是覆盖太广；或者「开放接单」被关掉了 |
| **没收到预约通知** | 后台「安全与备份 → 预约通知」看上次失败原因：`HTTP 403` = token 不对（回 pushplus.plus 重新复制）；`超时` = 对方没响应（换 Server酱试试）；`连不上` = 你填的网址不在出网白名单里。PushPlus / Server酱 **本来就在白名单里**，正常不需要申请 |
| **客户说"点了预约但你没理他"** | 后台「预约与时间」看当天列表的「客户自助预约」徽章，联系方式就在上面（微信 / 闲鱼 / QQ 都带前缀） |
| **收入页这个月是 ¥0，但你明明接过单** | ① 那些单是"老板自己锁的"还是"客户自助预约"？**只有客户自助预约点「已确认」才会自动记**；② 是不是 `price` 是 0（免费补偿单不记流水）；③ 剪辑 / PS / 建站这类一次性单子要手动点「+ 记一笔」 |
| **收入记重了 / 想删一笔** | 后台「收入」→ 流水明细那一行点「删」。同一单系统不会重复记（点两次「已确认」也只记一笔），所以真记重了多半是手动补记了两次 |
| **恢复备份之后收入还在吗** | 在（备份里带 `payments`）。**老备份**（还没有收入这一版导出的）导入时不会清空你现在的账，只是跳过收入那一步 |
| 想改代码 | 改完本地先跑 `python tests\run_tests.py`，九段全绿再推 GitHub |
