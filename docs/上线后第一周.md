# 上线后第一周该做什么

部署成功 ≠ 能接到单。这份是**从"网站能打开"到"收到第一个预约"**的操作清单。

> 所有按钮名字都和后台实际界面对得上（我逐条核对过）。

---

## 一、上线当天（约 20 分钟，按顺序做）

### 1. 改管理密码（第一件事）

后台 →「安全与备份」→ 修改管理密码。

→ 环境变量里的密码只用于首次启动；改了之后，旧 Cookie 会立刻全部失效。

### 2. 开预约通知（不做这步，客户下单你不知道）

后台 →「安全与备份」→「预约通知」：

```
通知渠道：PushPlus（微信推送）
Token 或网址：微信扫码登录 pushplus.plus 后复制的 token（32 位字符）
```

点「保存通知设置」→ 再点「发送测试通知」。

→ 微信里收到「陪玩站测试通知」就成功了；下面那行会显示**上次发送结果**，
失败会写原因（比如 `HTTP 403` = token 不对、`超时` = 服务器连不上外网）。

> 不配置也能接单，只是**客户自己锁了时间你不会收到提醒**，得自己常看后台。

### 3. 设固定休息

后台 →「预约与时间」→ 固定休息规则 → 添加：

```
重复星期：全部勾上
开始 / 结束时间：02:00 到 10:00
备注：睡觉休息
```

→ 不加这条，你的时间表会显示**全天 24 小时都能约**，凌晨三点也可能有人下单。

### 4. 检查资料与报价

后台 →「资料与报价」，重点看三处：

| 字段 | 为什么重要 |
|---|---|
| 微信号 | 客户唯一的联系入口，写错等于没生意 |
| 陪玩报价 | 客户选"模式"时看到的就是它 |
| 服务说明 | 下面第三节列了客户最常问的问题，答案都在这里，写清楚能省掉一半聊天 |

### 5. 传 3 张展示墙

后台 →「展示墙」→ 建议顺序：

1. **游戏截图**（带战绩/撤离成功的那种，最好有你的 ID）
2. **游戏截图**（能体现你擅长的图，比如大坝/机密）
3. **老板评价**（让老客户发你一句，截图或直接文字）

→ 3 张就够开张了。空着的展示墙会让客户觉得"这人是不是不接单"。

### 6. 设置保活（不做这步，数据会丢）

免费实例 **15 分钟没人访问就休眠，一休眠 SQLite 和图片全清空**（Render 官方文档写明的）。

注册 <https://uptimerobot.com> → Add New Monitor → Type 选 `HTTP(s)` → URL 填：

```
https://你的服务名.onrender.com/api/ping
```

→ Interval 选 **5 minutes**。这个接口不查数据库、只回 35 字节，专门用来"叫醒"实例。

### 7. 跑一次体检

在电脑上执行：

```bat
python tests\check_deployed.py https://你的服务名.onrender.com
```

→ 26 项检查（页面 / 微信分享卡片 / 时间表接口 / 后台保护 / 静态资源 / 保活 / 速度 / HTTPS）。
看到 `通过 26 项 | 失败 0 项` 才算真的上线成功。

### 8. 手机微信里实测一遍

把网址发给你自己的小号，检查四件事：

- [ ] 分享卡片有**标题、简介和小图**（没有的话微信会缓存旧卡片，过一会儿或换个链接再试）
- [ ] 点「复制微信号」，能弹出复制成功或"长按文字复制"的框
- [ ] 选几个时间 → 点「下一步：选择模式」→ 出现模式卡片 + 「联系方式」下拉（微信 / 闲鱼 / QQ）
- [ ] 填个联系方式 → 点「立即锁定时间」→ 看到"时间已锁定 ✅"，同时**你手机上收到一条预约通知**；
      再回后台「预约与时间」看，那条会带「客户自助预约」徽章，模式、价格、联系方式、下单时间都在

> 想先自己试又不想留脏数据：试完在后台点那条记录的「取消」，那几格立刻恢复可预约。

> 客户也可以点弹窗里的「只复制文案，不锁定」——那条路不锁时间，文案里会写明"时间还没锁定"。

## 二、发布：怎么让客户知道你有这个页面

**核心思路**：你发的不是广告，是"一个能自己看空档的页面"——它帮客户省事，所以不招人烦。

### 微信群 / 朋友圈（正式版）

> 做了个页面，能直接看我的空档时间，不用来回问"你几点有空"了：
> https://你的服务名.onrender.com
> 看中哪几格点一下、留个联系方式就锁上了，我这边马上收到消息；微信号也在页面里。

### 微信群 / 朋友圈（随意版）

> 现在我几点有空都能自己看了 👉 链接
> 不用再问我"在吗"，直接挑时间点下去，锁上我就来找你

### 闲鱼

商品描述里加一句：

> 具体空档时间看这里（实时更新）：https://你的服务名.onrender.com

### 发的时候注意

- **一次发一条**，别刷屏；群里发完就别反复顶
- 老客户可以**单独私聊**发，转化比群里高得多
- 朋友圈配一张**你自己最好的游戏截图**，比配链接预览更抓人

## 三、客户会问的问题（提前把答案写进「服务说明」）

| 客户会问 | 你的网站其实已经回答了 | 建议怎么写进「服务说明」 |
|---|---|---|
| 怎么算时间？ | 「以开第一局游戏为起点计时，时间打满」 | 保持默认那条，别删 |
| 怎么付钱？ | 网站不收款（故意的） | 加一条："微信/闲鱼先确认，开局前付或打完付都行" |
| 能不能改时间？ | 客户自己锁的格子，你可以在后台一键「取消」，格子立刻回到可预约 | 加一条："改时间提前 2 小时说一声，我放开格子" |
| 1 陪 2 要加钱吗？ | 「同一订单 1 陪 1 或 1 陪 2，不额外收取人数差价」 | 保持默认 |
| 玩什么图？ | 报价里的三档模式 | 在「打法标签」里把擅长的都写上 |
| 你靠谱吗？ | 「展示墙」 | 这是展示墙存在的唯一理由，别让它空着 |
| 点了预约就算约上了吗？ | 是的，**点了就锁定**，你也会收到通知 | 加一条："时间锁上后我会加你确认；临时有事提前说，我随时取消" |

## 四、每周 10 分钟的例行

| 做什么 | 在哪 |
|---|---|
| **导出备份** | 后台「安全与备份」→ 下载备份 JSON（超过 7 天没导出，后台顶部会弹提醒） |
| **看客户自助预约** | 后台「预约与时间」的统计卡「客户自助预约（待确认）」，或直接看当天列表里的「客户自助预约」徽章 |
| **确认/取消预约** | 后台「预约与时间」→ 选中日期 → 那条记录右边的「取消」（取消后格子立刻回到可预约） |
| 看上周接了几单 | 后台「预约与时间」的统计卡 |
| **检查通知还通不通** | 后台「安全与备份」→「预约通知」→「发送测试通知」 |
| 更新展示墙 | 「展示墙」→ 传新截图 / 新评价，旧的可以「归档」 |
| 调整休息规则 | 「预约与时间」→ 固定休息规则（作息变了就改） |

## 五、数据会告诉你的事

上线两三周后，回头看你的预约记录，会有两个明显信号：

- **某几个时段总被约满** → 说明那是黄金时段，可以涨价，或者干脆少放几个格子（稀缺反而更好卖）
- **某些时段从来没人约** → 直接设成固定休息，少被打扰、也不用一直看手机

## 六、什么时候该花钱升级（$7/月）

免费档能用，但这三种情况建议升级到 `0.5c-512mb` + 挂 1GB 持久磁盘（合计约 $7.25/月）：

1. **一周能接 10 单以上** —— 数据开始值钱了，别拿免费档赌（休眠就清空）
2. **有客户说"第一次打开等了好久"** —— 免费档休眠后要等约 1 分钟冷启动，很劝退
3. **你开始懒得导出备份了** —— 持久磁盘一挂，这件事就永久解决了

升级步骤在 [DEPLOY.md](DEPLOY.md) 的「最重要的一节」里。

## 七、出问题时的顺序

| 现象 | 先做什么 |
|---|---|
| 网站打不开 | 先在电脑上跑 `python tests\check_deployed.py 你的网址`，看哪一项失败 |
| 后台进不去 | 密码错了？或者换浏览器（Cookie 被禁会一直跳回登录页） |
| 数据不见了 | 大概率是休眠被清空了 → 后台「从备份恢复」把 JSON 导回去 → 然后赶紧设保活 |
| 时间表状态不对 | 检查「固定休息规则」是不是覆盖太广；或者「开放接单」被关掉了 |
| **没收到预约通知** | 后台「安全与备份 → 预约通知」看上次失败原因：`HTTP 403` = token 不对（回 pushplus.plus 重新复制）；`超时` = 对方没响应（换 Server酱试试）；`连不上` = 你填的网址不在出网白名单里。PushPlus / Server酱 **本来就在白名单里**，正常不需要申请 |
| **客户说"点了预约但你没理他"** | 后台「预约与时间」看当天列表的「客户自助预约」徽章，联系方式就在上面（微信 / 闲鱼 / QQ 都带前缀） |
| 想改代码 | 改完本地先跑 `python tests\run_tests.py`，接口 120 项 + 预约 75 项全绿再推 GitHub |
