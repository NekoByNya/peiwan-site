# 如果东西删了 / 想换网址，怎么办

这份文档回答两个问题：**① 万一某个东西没了，怎么恢复？② 想换网址怎么换？**

先记住一句话：

> **你的网站跑在 PythonAnywhere 的服务器上，不需要你的电脑、不需要任何 AI 软件、不需要我。**
> 只要 PythonAnywhere 还在跑，你关电脑、删文件夹、换电脑，网站都照常营业。

---

## 一、代码一共有三份（删一份不影响）

| 位置 | 里面有什么 | 用途 |
|---|---|---|
| **① PythonAnywhere** `/home/你的用户名/peiwan-site/` | 正在运行的代码 **+ 你的全部数据** | 网站本体 |
| **② GitHub** `github.com/你的用户名/peiwan-site` | 代码备份（**不含数据**） | 代码永远不会丢 |
| **③ 你的电脑** `...\default-workspace\peiwan-site\` | 代码 + 本地测试数据 | 改代码用 |

**数据（预约记录、价格、上传的图）只在两个地方**：
- PythonAnywhere 的 `data/` 目录（主）
- **你后台导出的备份 JSON**（副本 —— 所以这个习惯最重要）

---

## 二、四种"删了"的情况

### 情况 1：本地文件夹删了（最轻）

代码在 GitHub 上，一条命令拉回来：

```bash
git clone https://github.com/NekoByNya/peiwan-site.git
```

拉回来的是**代码**；本地那份 `data/` 里如果有你练习用的数据，没了就没了（线上数据不受影响）。

想连本地数据一起恢复：后台 →「安全与备份」→ 下载备份 JSON → 本地后台「从备份恢复」。

### 情况 2：GitHub 仓库删了

去 GitHub 重新建一个同名仓库，然后在 **PythonAnywhere 上重新上传代码**：

```bash
cd ~/peiwan-site
git remote set-url origin https://github.com/你的用户名/新仓库名.git
git push -u origin main
```

> 代码在服务器上是完整的（含 `git` 提交历史），所以反过来也能当备份源。

### 情况 3：PythonAnywhere 网站/账号没了（最严重）

**代码**：从 GitHub 重新部署（照 [`DEPLOY-PYTHONANYWHERE.md`](../DEPLOY-PYTHONANYWHERE.md) 走一遍，10 分钟）

**数据**：用**备份 JSON** 恢复 —— 后台 →「安全与备份」→「从备份恢复」→ 选那个 JSON 文件。

**备份里到底有什么**（我核对过代码，`build_backup()`）：

| 内容 | 在备份里吗 |
|---|---|
| **全局资料**（品牌名、昵称、微信号、简介、信任信号、首页背景图…） | ✅ |
| ★ **大类**（陪玩 / 代肝 / 其他服务，含改名和类型） | ✅ |
| ★ **分区**（`/z/xxx` 那些招牌页：名字、简称、主色、排序、是否隐藏） | ✅ |
| ★ **每个分区的资料**（价格、价目表、文案、服务承诺…） | ✅ |
| ★ **每个分区的那几张图**（背景图 / 首屏图 / 分享图 / 价目表长图） | ✅ 打包成 base64 一起存（`zoneImages`） |
| 所有预约锁定 + 固定休息规则（含"这单来自哪个分区"） | ✅ |
| 展示墙条目（标题、说明、分类、是否公开、**属于哪个分区**） | ✅ |
| **展示墙的图片本身** | ✅ 打包成 base64 一起存 |
| **头像 / 微信二维码 / 首页背景图** | ✅ 同上（`profileImages`） |
| 管理密码 | ❌ 不在里面，恢复后要重新设一次 |

> **一句话：分区数据也随备份 JSON 一起走。** 换服务器时，分区、价格、每张图都能一起回来，
> 不用重新配一遍。（老备份文件也照常能导入：里面没有分区那一段时会跳过分区，
> 预约、资料、展示墙照常恢复，现在配好的分区不会被清空。）

> 唯一的例外：**单张超过 3MB 的图**不会塞进备份（避免 JSON 过大）。
> 正常上传的图会被浏览器自动压缩到 1600px，一般 100–300KB，都在限制内。

⚠️ **所以结论是**：只要你有备份 JSON，**换服务器后连图片都能一起恢复，一条数据都不丢**。
反之，如果从没导出过备份，那数据（和图片）就真的没了 ——
**这就是为什么每月要导出一次备份。**

### 情况 4：我不在了 / 不用这个 AI 了 / 换电脑了

**完全不影响。** 你的网站是标准的 Python 程序：

- 管理网站：浏览器打开 pythonanywhere.com（任何电脑、手机都行）
- 改代码：浏览器打开 github.com 就能在线编辑
- 看文档：`docs/` 里有 5 篇中文说明，全在 GitHub 上

**没有任何一步需要 AI 或特殊软件。**

## 三、想换网址怎么办

### 先说清楚：网址是怎么来的

PythonAnywhere 免费版的网址 = `你的用户名.pythonanywhere.com`，
所以现在是 **你的用户名.pythonanywhere.com**。

**用户名不能改**，所以想换网址只有三条路：

| 办法 | 新网址长什么样 | 代价 |
|---|---|---|
| **① 注册一个新账号** | `新用户名.pythonanywhere.com` | 免费；要重新部署一次（10 分钟）+ 从备份恢复数据 |
| **② 升级到付费版（$5/月）** | 绑你自己的域名，如 `baixu.com` | 要一张能过国际支付的卡；域名本身还要另买（约 ¥60/年） |
| **③ 换平台** | Render：`xxx.onrender.com`（也支持自定义域名） | 要卡；而且免费档会休眠、数据会清空 |

### 换个账号重新部署（办法 ①，详细步骤）

1. 注册新 PythonAnywhere 账号（新用户名就是你想要的新网址）
2. **先在旧站导出备份**：后台 →「安全与备份」→「下载备份 JSON」
3. 新账号里照 [`DEPLOY-PYTHONANYWHERE.md`](../DEPLOY-PYTHONANYWHERE.md) 走一遍：
   - Bash：`git clone https://github.com/NekoByNya/peiwan-site.git`
   - Web → Add a new web app → **Manual configuration** → Python 3.x
   - 填 Source code / Working directory
   - 写 WSGI 文件（命令在文档里）
   - 配 Static files：`/static/` → `/home/新用户名/peiwan-site/static`
   - **Reload**
4. 进新站后台 →「从备份恢复」→ 上传第 2 步的 JSON
   （**分区、每个分区的价格和图片都会一起回来**，不用重新配）
5. 进新站后台 →「修改管理密码」→ 设一个新密码（**别用旧的那个**）
6. 打开 `/z/每个分区` 各看一眼（图还在不在、价格对不对），再把新网址发给客户；
   旧网址可以留着做个跳转说明，或者直接删掉网站

> ⚠️ 旧账号的网站要记得处理：Web 页面最下面有「Delete this web app」。

## 四、日常最该养成的三个习惯

| 频率 | 做什么 | 为什么 |
|---|---|---|
| **每月** | 去 PythonAnywhere 的 Web 页面点一次黄色 **「Run until 1 month from today」** | 不点网站会被停（数据还在，点一下就好） |
| **每月** | 后台「安全与备份」→ 下载一次备份 JSON，存到网盘/微信收藏 | 万一服务器出事，数据能一条不丢地回来 |
| **改代码时** | 本地改 → `python tests\run_tests.py` 全绿 → 推 GitHub → 服务器 `git pull` + Reload | 出错能回滚，网站不会挂 |

## 五、最坏情况的"从零重建"清单

假设一切都没了（电脑坏了、GitHub 忘了、服务器没了），只剩这份文档和你记得的密码：

- [ ] 注册 PythonAnywhere（[链接](https://www.pythonanywhere.com/registration/register/beginner/)）
- [ ] 建 GitHub 账号（如果要改代码）
- [ ] 从 GitHub 拉代码，或从网盘找 `peiwan-site-上传用.zip`
- [ ] 照 [`DEPLOY-PYTHONANYWHERE.md`](../DEPLOY-PYTHONANYWHERE.md) 部署（10 分钟）
- [ ] 后台「从备份恢复」导入数据（**分区和分区里的图片也会一起回来**）
- [ ] 后台改密码、改全局资料、逐个分区检查价格和图
- [ ] 后台配通知（PushPlus token 重新拿一个）
- [ ] 把新网址发给客户

**代码能从 GitHub 回来，数据能从 JSON 备份回来，剩下都是 10 分钟的点击。**
所以真正要守住的只有两样：**GitHub 账号** 和 **每月那份备份 JSON**。
