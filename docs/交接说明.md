## 一、这是什么

  要给"照着点就行"的具体步骤（能截图就截图）。
- 他的需求永远围绕三件事：**省钱（免费托管）、省事（不要复杂运维）、能接单**。

## 四、必须知道的坑（踩过一遍了）

1. **`wsgi.py` 里必须调用 `site.init_db()`** —— `app.py` 的 `main()` 只在"直接运行"时执行，
   WSGI 模式不会执行，少了这一行，**所有读数据库的页面（含主页）都会 500**，而 `/api/ping` 正常。
2. **改 `app.py` 会让 `docs/代码导读.md` 的行号漂移** —— `tools/check_docs.py` 会报 `[漂移]`，
   按提示把行号改对即可（这个校验器就是为此存在的，别绕过它）。
3. **文档里引用的「」UI 文案也被校验** —— 改前台按钮文字，要同步改文档。
4. **改数据库表结构必须用 `ensure_column()`** —— 老库已经存在，`CREATE TABLE IF NOT EXISTS`
   不会加字段；直接改 SCHEMA 会导致线上老库缺列报错。迁移要幂等、不能丢老数据。
5. **零第三方依赖** —— 只能用 Python 标准库（`urllib`/`sqlite3`/`http.server`…），
   不要引入 `requests`、`flask`…（PythonAnywhere 免费版也不让随便装）。
6. **写文件不要用 PowerShell 的 `Set-Content -Encoding UTF8`** —— 会加 BOM，破坏 Python 解析。
7. **PythonAnywhere 出网有白名单** —— 别随便加"调用某个 API"的功能，先查
   <https://www.pythonanywhere.com/whitelist/>（PushPlus / Server酱 / 飞书 / 钉钉 / ntfy 在里面）。

## 五、已经做好的功能

- 主页：7 天 × 24 小时时间表，5 种格子状态（可约 / 已预约 / 休息 / 已过去 / 停接）
- **客户自助预约**：选时段 → 选模式 → 填联系方式（微信 / 闲鱼 / QQ）→ **立即锁定**
  - 限制：单次最多 6 小时、同一 IP 10 分钟最多 5 次、联系方式必填（2–40 字）
  - 冲突返回 409 并告诉客户哪几格没了；限流返回 429
  - 也保留了"只复制文案、不锁定"的旧路径
- 后台：预约列表（来源徽章 / 模式 / 价格 / 联系方式 / 备注 / 下单时间）、取消预约、
  固定休息规则、资料与报价、展示墙（传图自动压缩）、改密码、备份导出与恢复
- **预约通知**：PushPlus / Server酱 / 自定义 Webhook，后台可"发送测试通知"，
  成功失败都记在 `notify_last` 里显示给主人看
- 微信分享：服务端注入 og 标签（标题/简介/1200×630 缩略图）
- 195 项自动测试 + 文档校验 + 前端引用校验
