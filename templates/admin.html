导出业务备份

下载一个 JSON 文件，里面有你全部的预约时段、休息规则、资料、展示墙数据，连图片也打包在里面。建议每月导出一次，免费的 Render 实例重新部署会清空数据。

下载备份 JSON

为什么要勤备份：免费的 Render 实例每次休眠、重启、重新部署都会清空数据。 解决办法见项目里的 DEPLOY.md（保活定时访问 / 挂持久磁盘）。

从备份恢复

选择之前导出的备份 JSON。会整体覆盖现在的预约时段、休息规则、资料和展示墙（图片会一起恢复）。

预约通知

客户在前台自助预约后，立刻推一条消息到你手机。不配置也能正常接单，只是不会收到提醒。
