▾

客户在前台自助预约时，那几格立刻就被锁走了。加得上微信、谈得拢，就点「已确认」； 联系不上、或者他放你鸽子，就点「释放时段」把那几个小时还给别人。 没确认的单会一直留在这里提醒你，不会自己消失。

⚠️ 打开了就真的会删：超过这个小时数还没确认的客户预约会被自动释放（时段回到可约）。 三条安全线：只删客户自助预约（你自己锁的一律不碰）、只删已经确认过的以外 （你点过「已确认」的不碰）、只删还没开始的时间（已经过去的不碰）。 释放过哪几单会记在下面，随时能查。

⏳ 这份时间表是全部服务共用的：客户不管从哪个分区（三角洲 / 守望 / …）进来， 占的都是同一批时段。所以这里只有一个时间表，不需要按分区各管一套。

客户看到的每一句话

这些就是客户在首页、分区页、下单弹窗、页脚里看到的中文。 留空 = 用默认那句话。改完点「保存文案」，前台立刻生效（让客户刷新一下页面就能看到）。

⚠️ 三条要知道的：① 文案是纯文本，写 <b>加粗</b> 不会被当成标签，会原样显示出来； ② 带花括号的 {name} {zone} {max} 是"变量" （分别会变成你的昵称 / 分区名 / 一次最多几小时），别删掉，不然那句话就和实际规则对不上了； ③ 每一行左边的字是"这句话出现在哪"，右边的框才是你要改的内容。

服务条款（客户点开 /terms 看到的那一页）

这一页是给客户看的"把话说清楚"：服务内容、怎么下单、怎么付钱、取消与改期、 账号安全、责任范围、怎么找你。默认那份是照"个人接单"的实际情况写的，可以直接用，也可以改成你自己的口气。

正文里空一行 = 另起一段，单独换行就是换行。正文里写 {wechat} 会自动变成你的微信号 （换了微信号不用回来改这里）。「最后更新」的日期是你每次点保存那天自动写上的。

常见问题（客户在预约后面看到的那个折叠块）

客户在预约前后犹豫的时候，心里那几个问题（账号安全吗 / 打不完怎么算 / 能退款吗） 就在这里回答他。分区页里它是预约后面的独立一块（左侧导航里叫「问答」）， 每条一个能点开的折叠块（默认收起）。 ★ 想让这一整块也折叠起来？去上面「② 分区页 · 价目」那一组填 faqPanelSummary（留空就不折叠，就是现在这样）。

这条最常见，所以默认给你写了 8 条，可以直接用，也可以改成你自己的口气。 答案里空一行 = 另起一段，单独换行就是换行；写 {wechat} 会自动变成你的微信号。

服务流程（客户从"看到"到"下单"要走几步）

客户第一次来最怕的是"我点一下会发生什么"。把几步写清楚，他就知道点完还有人在后面接住。 分区页里它是档位卡下面那个折叠块（默认收起）， 折叠时右边那串字 = 这几步的名字自动拼出来的（你改了上面的步骤名，它自动跟着变）。 展开后编号会显示成 01 / 02 / 03 那种圆圈。

2 ~ 6 步：少于 2 步不成流程（会先用默认那 4 步顶着），多于 6 步客户就不看了。 详情里的 {wechat} 一样会自动换成你的微信号。

分类管理

展示墙的分类现在可以自己加了 —— 游戏截图 / 老板评价 / 作品只是默认的三个。 客户在前台看到的就是这几个筛选按钮。改名字随时可以，短标识（id）不能改， 因为已经传上去的图是靠 id 认分类的。分类底下还有图时会拦着不让删，免得图悄悄换组。

修改管理密码

改完密码后，所有已登录的设备都会退出，需要重新登录。

导出业务备份

下载一个 JSON 文件，里面有你全部的预约时段、休息规则、资料、分区（含每个分区的价格和图片）、展示墙数据，连图片也打包在里面。建议每月导出一次。

下载备份 JSON

为什么要勤备份：免费的 Render 实例每次休眠、重启、重新部署都会清空数据。 解决办法见项目里的 DEPLOY.md（保活定时访问 / 挂持久磁盘）。

从备份恢复

选择之前导出的备份 JSON。会整体覆盖现在的预约时段、休息规则、资料、分区和展示墙（图片会一起恢复）。

老备份（还没有分区概念的版本）也能导入：里面的预约、资料和展示墙会照常恢复，分区保持现状不动。
