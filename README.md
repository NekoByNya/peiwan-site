# Nya 的个人服务招牌站 · 从零手写版

> ## 🤖 如果你是 AI 助手，或者第一次接手这个项目
>
> **请先读 [`docs/交接说明.md`](docs/交接说明.md)** —— 那一页写清了：
> 项目现在跑在哪、怎么改代码、有哪些坑（踩过的）、安全规矩、以及主人需要什么样的帮助。
>
> 读完之后配合本文件和 [`docs/代码导读.md`](docs/代码导读.md) 就能完全上手。

这是**属于你自己的**个人服务网站：**一个人做多种服务，一个网站全放下**。
零第三方依赖（PIL 只是给"自动取主色"用的，没装也能跑）、每一行都写了中文注释，就是给你学着改的。

```
/            个人主页：品牌 + 我能做什么（按大类分组）+ 信任信号 + 加微信
/z/delta     三角洲行动陪玩   → 按小时，选时段、点一下立刻锁定
/z/overwatch 守望先锋陪玩     → 同上，**和三角洲共用同一份时间表**
/z/arknights 明日方舟代肝     → 包月/包干，只有价目表，不需要时间表
/z/editing   视频剪辑         → 交需求报价，同上
```

**两级分区**：**大类**（陪玩 / 代肝 / 其他服务）决定"要不要时间表"，
**分区**（三角洲 / 守望 / 明日方舟…）就是一个个招牌页 —— 背景图、首屏图、分享图、
价目表全都是**每个分区独立一套**，在后台点几下就能加，**不用改代码**。

> ⏳ **时间表是全局共用的**：不管客户从哪个分区进来，占的都是同一批时段。
> 你只有一份时间，代码就是照这个事实写的。

**Windows**：双击 `start.bat`（或在命令行里执行）：


看到下面这样就说明成功了：

```

 管理后台：http://127.0.0.1:8123/nya-0508
```

- 主页：<http://127.0.0.1:8123>
- 后台：<http://127.0.0.1:8123/nya-0508>　初始密码 **baixu123**（登录后请立刻改）

> 🔑 **后台网址是个"暗号"**（`/nya-0508`，不是 `/admin`）。为什么要这样：
> 自动扫描机器人一天到晚在扫全网的 `/admin`、`/wp-admin`，把门牌换个名字它们就找不到门了

## 三、第一次使用，按这个顺序做

1. **改密码**：后台 →「安全与备份」→ 修改管理密码（至少 6 位）。
2. **填全局资料**：后台 →「资料与报价」→ 最下面「全局资料」，
   品牌名（首页大标题）、昵称、微信号、头像、信任信号（每行一条）。
3. **建你的分区**：后台 →「分区管理」→ 每个大类下面点「+ 新增分区」。
   （老站升级上来时，系统已经用你原来的内容建好了第一个分区 `delta`。）
4. **逐个分区填内容**：后台 →「资料与报价」→ 最上面选一个分区 →
   传图（背景图 / 首屏图 / 分享图 / 价目表长图）→ 填价格 → 点「保存这个分区」。
5. **设固定休息**：后台 →「预约与时间」→ 固定休息规则 → 建议第一条填
   `每天 02:00 – 10:00`，备注「睡觉休息」。不加这条，时间表会显示全天 24 小时都能约。
6. **开预约通知**（强烈建议）：后台 →「安全与备份」→「预约通知」→ 选 PushPlus、
   把 token 填进去 → 点「发送测试通知」。**有人下单你手机上立刻收到**。
7. **收预约**：客户在陪玩分区选好时间 → 点「立即锁定时间」→ 填联系方式 →
   **那几格立刻就被锁定了**（别的分区也同时看到这几格被占），你会收到一条通知。
   ⚠️ 这条单会先挂在「预约与时间」最上面的**待确认区**，等你点「已确认」或「释放时段」（见第六节）。
8. **传展示墙**：「展示墙」标签页 → 先选这张图属于哪个分区 → 传图 → 勾「立即公开」。
   剪辑/建站的作品可以再填一个**外链**（B 站视频地址 / 你做的网站），客户点图就能看成品。

### 预约通知怎么配（PushPlus，3 分钟）

1. 手机微信扫码登录 <https://www.pushplus.plus>（免费版每天 200 条，够用）；
2. 首页「一对一推送」那里能看到你的 **token**（一串 32 位字符），复制它；
3. 回到后台 →「安全与备份」→「预约通知」→ 渠道选 `PushPlus（微信推送）` → 把 token 粘进
   「Token 或网址」→ 点「保存通知设置」；
4. 点「发送测试通知」，微信里应该立刻收到一条「陪玩站测试通知」；
5. 下面那行小字会显示**上次发送结果**：绿色=成功，红色=失败并写明原因。

> 也可以用 **Server酱**（`https://sct.ftqq.com` 拿 SendKey）或**自定义 Webhook**
> （填一个网址，我们会 POST `{"title","content","text"}` 过去，方便接你自己的机器人）。
> 渠道选「关闭」就完全不发通知——客户照样能自助预约，只是你收不到提醒。

## 四、核心概念（看懂这 7 条，网站就全懂了）

### 0. ★ 两级分区：大类 + 分区

```
大类（categories，不能删，只能改名/改类型/排序）
  ├─ 陪玩      kind=booking → 它下面的分区**显示时间表**，价格是「三档数字」
  ├─ 代肝      kind=service → 它下面的分区**不显示时间表**，价格是「分组价目表」
  └─ 其他服务  kind=service → 同上

分区（zones，可以随便加/改/隐藏/删）
  ├─ delta      三角洲行动 /z/delta    ← 陪玩类，有时间表
  ├─ overwatch  守望先锋   /z/overwatch
  ├─ arknights  明日方舟   /z/arknights ← 代肝类，只有价目表
  └─ editing    视频剪辑   /z/editing
```

- 每个分区的**背景图 / 首屏图 / 分享图 / 价目表长图 / 主色 / 价格 / 文案**都是**独立一套**；
- **`kind` 挂在大类上**：把「代肝」大类改成预约制，它下面所有分区一起变成有时间表；
- **时间表是全局共用的**（见下面第 2 条）—— 分区只决定"展示什么"，不决定"卖什么时间"。

### 1. 一个格子有 5 种状态

| 状态 | 含义 | 谁能改 |
|---|---|---|
| `free` 可预约 | 空着，客户能点 | 自动 |
| `booking` 已预约 | 客户自助预约，或你手动锁的单子 | 客户自助预约 / 后台锁定 |
| `rest` 休息 | 被「固定休息规则」或手动休息覆盖 | 后台 |
| `past` 已过去 | 这个小时已经过去了 | 自动（按时间算） |
| `closed` 停接 | 你关掉了「开放接单」总开关 | 后台一个勾 |

判断顺序写在后端 `slot_status()` 里：**先看是否过去 → 再看是否被锁定 → 再看规则 → 再看总开关**。
想改哪个优先，就调这个函数的顺序。

> 另外每条**客户自助预约**还有一个自己的状态：**待确认 / 已确认**（`locks.confirmed`）。
> 那是"这单算不算数"，和格子的 5 种状态是两回事 —— 待确认的格子**照样是 booking（别人约不到）**，
> 只是后台会一直提醒你去处理。见「七之五」。

### 2. 时间表怎么来的（★ 所有分区共用这一份）

`build_slots()` 每次请求都现场生成 **今天 0 点起、未来 7 天 × 24 小时 = 168 个格子**。
它不是存在数据库里的，而是"**用规则算出来的**"——所以你改一条休息规则，整周时间表立刻变。

> ⚠️ **它连分区参数都没有**：`GET /api/public?zone=守望` 和 `?zone=三角洲` 返回的 168 格
> **完全一样**。守望的客户锁了晚上 8 点，三角洲的客户那边晚上 8 点也立刻变成"已预约"。
> 这是故意的 —— 你只有一份时间。（`tests\test_zones.py` 里有一条断言专门守着这件事。）

> 想改成显示 14 天？把 `app.py` 里的 `DAYS_SHOWN = 7` 改成 14 就行。

### 3. 两条路：自助锁定（主）和只咨询（次）

**主路径 —— 客户点一下就锁**：

```
客户在某个陪玩分区 /z/xxx 选好格子 →「下一步：选择模式」→ 选模式 + 填联系方式（微信 / 闲鱼 / QQ）
      ↓
点「立即锁定时间」→ POST /api/book（带 zone=这个分区的 id）
      ↓
后端复查空档（同一秒被别人抢了就返回 409 让客户重选）
      ↓
连续的格子合并成几段 → 每段一条 source='client' 的锁
（模式、总价、联系方式、下单时间、**来自哪个分区**一起存）
      ↓
这条锁同时被标成 **confirmed=0（待确认）** → 挂在后台「预约与时间」最上面
      ↓
客户看到成功页（锁了哪几段、总价、可复制文案）；你手机上收到一条通知
```

- 一次最多锁 **6 小时**（`app.py` 的 `MAX_BOOK_HOURS`），防止有人一口气占满你一周；
- 同一个 IP **10 分钟最多提交 5 次**（`BOOK_RATE_MAX`），超过返回 429；
- 联系方式**必填**：锁了时间却联系不上人，等于白锁；
- ★ **只有"预约制"大类下的分区能约时间**：代肝、剪辑这种包干的服务分区来调 `/api/book`
  会返回 400「不支持时段预约」——它们本来就没有时间表可占。
- ★ **时间锁走了，但单子等你点头**：客户自助预约的锁是"待确认"状态，
  你点「已确认」才算认下来，点「释放时段」就把那几格还回去（见「七之五」）。

**次路径 —— 只复制文案、不锁定**：弹窗里那个「只复制文案，不锁定」按钮保持不变，
适合客户想先问清楚再下单的情况，文案里会写明"时间还没锁定"。

> 文案里的游戏名来自**这个分区自己的资料**（`profile.game`）：
> 从守望分区下单，生成的就是「想约守望先锋 PC 电脑端陪玩」。

### 4. 后台有 8 张表

- `store`：放全局资料（JSON）、**大类列表**、**展示墙分类**、密码（加盐哈希，数据库里看不到明文）、
  **通知配置**、**自动释放设置**
- `zones`：★ **分区**。一行一个招牌页：`id`（网址里用）、`category`（属于哪个大类）、
  `name` / `short` / `icon` / `theme`（主色）、`sort`、`visible`、
  `profile`（这一分区自己的资料 JSON：价格、文案、四张图）
- `locks`：被锁定的时段。`kind` 是 `booking` 预约 / `rest` 休息；
  `source` 是 `owner`（你自己锁的）/ `client`（客户自助预约）；
  客户自助预约的还会记下 `mode`、`price`、`contact` + `contact_type`、`created_at`，
  以及 **`zone`（这单来自哪个分区）**。
  ★ 还有 **`confirmed`**（1 = 已确认，0 = **待确认**）和 `confirmed_at` —— 见「七之五」。
  ⚠️ `zone` 只是一个标记：**时段本身是所有分区共用的**，不是"每个分区各锁一套"
- `rules`：固定休息规则（按周重复，支持跨午夜）
- `gallery`：展示墙。每条都带 `zone`（出现在哪个分区页）、
  `category`（分类 id，**默认三类可在后台改**）和 **`link`（外链，见「七之四」）**
- `customers`：★ **客户档案**。一行一个客户：称呼、联系方式、
  关联的分区 / 档位 / **金额（自由文本）**、开始日、**到期日**、状态、备注。
  `end_date` 留空 = 一次性/长期，不算到期，永远不会催你。详见下一节。
- `payments`：★ **收入流水**（见「七之六」）。一行一笔钱：
  **日期**（"YYYY-MM-DD"，北京时间）、**金额（★ 全站唯一要求是数字的地方）**、
  分区 / 项目 / 客户称呼、**来源**（确认预约 / 续费 / 手动补记）、
  **`ref`（防重复记账的标记）**。客户档案里的金额仍然是自由文本，这两个不冲突。

> 老数据库升级上来也不会丢数据：`init_db()` 里有 `ensure_column()`（字段缺哪个补哪个）
> 和 `migrate_to_zones()`（把"单游戏时代"的旧资料搬进第一个分区 `delta`，只做一次）。
> 你以前锁过的时段、展示墙、休息规则**一条都不会动**，只是多了一个 `zone` 标记。

### 5. 预约通知怎么发

- 渠道：**PushPlus**（微信推送，推荐）、**Server酱**、**自定义 Webhook**、关闭
- 发送是**丢到后台线程**里做的：客户提交完立刻拿到结果，不用等这个网络请求；
- 成功还是失败都记在 `store` 的 `notify_last` 里，后台「预约通知」下面直接显示
  （失败会带原因，比如 `HTTP 403`、`超时`）；
- 发送超时 10 秒，发不出去只会影响"你有没有收到提醒"，**绝不影响客户下单**。

### 6. 登录是怎么做的

登录成功后服务端发一个 Cookie，里面是「过期时间 + 用密码哈希签名的指纹」（`HttpOnly`，JS 读不到）。
**服务器不保存任何会话**——所以你重启网站、重新部署，只要 Cookie 没过期就还是登录状态；
而你一改密码，签名密钥跟着变，所有旧 Cookie 立刻失效。有效期 12 小时。

## 五、数据、备份、恢复

> **先记住这一条**：免费的 Render 实例**每次休眠（15 分钟没人访问）都会清空 `data/`**。
> 解决和缓解办法写在 [DEPLOY.md](DEPLOY.md) 的「最重要的一节」：定时保活 / 挂持久磁盘 / 勤导出备份。
> 后台会在你超过 7 天没导出备份时弹提醒。

- 所有数据在 `data/site.db`（SQLite 单文件）+ `data/uploads/`（图片）。
  旁边可能还有 `site.db-wal`、`site.db-shm` 两个文件——那是 SQLite 的并发日志，**别删**，
  它们和 `site.db` 是一套的（备份时用后台的「下载备份 JSON」，不要直接拷 .db 文件）。
- 后台「安全与备份」→「下载备份 JSON」导出**全部**业务数据：全局资料、**大类 + 每个分区
  （含它的价格、文案、主色）**、预约时段（含来源、模式、价格、联系方式、下单时间、分区、
  **待确认状态**）、休息规则、展示墙（**含外链和分类**）、**客户档案（谁哪天到期、
  买了什么档位、多少钱）**、**展示墙分类、自动释放设置和最近的释放记录**，
  **连图片也一起打包在里面** ——
  全局的图放在 `profileImages`，每个分区的四张图放在 `zoneImages`
  （单张超过 3MB 的图不会打包，避免备份文件太大）。
- 后台「安全与备份」→「从备份恢复」可以把备份**整个写回去**，分区、价格、图片和客户都会重新生成。
  这是给免费 Render 实例准备的：**它每次重新部署都会清空 `data/`，先导出一份就不会白干**。
  （**老备份也能恢复**：里面没有 `zones` / `categories` 时会跳过分区那一步，
  预约、资料、展示墙照常恢复，你现在配好的分区不会被清空；
  没有 `customers` 时同理 —— **你的客户档案一条都不会被清掉**；
  没有 `confirmed` 字段时，恢复回来的锁一律算"已确认" ——
  **不会让一份老备份凭空造出一堆待确认**。）
- 换电脑/重装：把 `data/` 整个文件夹拷过去就行。
- 想清空重来：关掉网站，删掉 `data/` 文件夹，再启动（会重新生成默认资料和一个示例分区）。

> **升级到这一版不用做任何手工迁移**：启动时 `init_db()` 会自动补字段、建大类、
> 并把老的资料搬进第一个分区 `delta`（只做一次）。你以前锁过的时段、休息规则、
> 展示墙都会原样保留，只是都挂到了 `delta` 名下。

## 七之二、★ 怎么加一个新分区（后台点几下就行）

假设你想加一个**「永劫无间陪玩」**：

```
① 后台 →「分区管理」→ 找到「🎮 陪玩」这一组 → 点「+ 新增分区」
      分区全称：永劫无间
      简称：永劫          （顶部标签上显示它，2–4 个字最好）
      短标识：naraka      （英文小写，会变成网址 /z/naraka；不能和已有的重复）

② 建完会自动跳到「资料」，并且已经选中这个新分区。按顺序填：
      · 游戏名        ：永劫无间          ← 预约文案里会写成「想约永劫无间 …」
      · 接单平台      ：PC 电脑端
      · 一句话简介    ：上分、陪玩、带新手
      · 首屏大标题    ：两行都可以（换行 = 两行）
      · 详细介绍 / 服务亮点（逗号隔开）/ 公告

③ 传图（五个位置，都可以先留空）：
      【分区图标】    首页卡片上的小图，正方形最好（建议 600×600 左右，PS 里压到 200KB 以内）
      【分区背景图】  铺满分区首屏，横图（建议 1920×1080）
      【首屏主视觉】  放在大标题旁边，**PNG 透明底**最好看（建议 1200 高）
      【微信分享图】  1200×630 —— 客户转发这个分区时显示的卡片图
      【价目表长图】  只有代肝/剪辑这类"服务型"分区才用（PC 上做一张长图直接贴上来）

④ 选主色：
      点「从首屏图自动提取主色」→ 系统会用你首屏图里的主色调算出颜色填进取色器；

⑤ 填价格：**去「报价」标签页**（报价和资料是分开的两页，改一边不影响另一边）——
      页面顶部先选「给哪个分区定报价」，选中你刚建的分区，然后：
      · 陪玩类（预约制）：填「三档价格」——名称 / 说明 / 每小时价格（数字）
      · 代肝·剪辑类（服务制）：填「价目表（分组）」——

              普通托管 | 20R/月 | 日双清+每周返图
              半精托管 | 55R/月 | 加活动代打
              精托托管 | 100R/月
          价格是**自由文本**，你写什么就显示什么（不会自动改成 ¥）。
          想让某几档出现在最显眼的位置：勾它右边的「主推」，或者点「主推」按钮
          （最多 3 个，会显示在分区页第一屏）。

⑥ 回到「资料」页点「保存这个分区」，在「报价」页点「保存报价」
      → 打开 /z/naraka 看效果（手机上也要看一遍）。

   ★ 传了图一定要点「保存这个分区」——图是先在浏览器里排队，点了保存才真的写进数据库。
```

**几个坑，先知道**：

| 现象 | 原因 |

| 分区页没有时间表 | 它属于「服务制」大类（代肝 / 其他服务）。想让它能约时间，去「分区管理」把那个大类改成「预约制」 |

| 「删除」点了还问好几遍 | 故意的：删分区不可恢复，弹窗里写清了会牵连什么。只想下架就点「👁 隐藏」 |

## 七之三、★ 怎么管客户和催续费（每天 1 分钟的那个页面）

> **这一节是给"包月单子"用的。** 陪玩按小时，客户自己会来找你；
> 但**代肝是包月的** —— 客户 8 月 20 日到期，你要是那天没想起来问一句，
> 他多半也不会主动说，单子就这么悄悄没了。
> 丢一个 50R/月的客户 = 一年 600R。所以这个页面存在的唯一目的就是：
> **让你每天花 1 分钟，就知道今天该催谁。**

### 每天的动作（4 步，30 秒）

```
① 后台 →「客户」标签页（在「预约与时间」右边）
② 看最上面 4 张卡片：🔴 已超期 / 🟠 3 天内到期 / 🟡 一周内 / ⚪ 进行中
③ 看「本周需要催的客户」那张清单，从上往下一个一个处理
④ 每行点「复制催续费话术」→ 切到微信 → 粘贴 → 发送
   客户说"续"，就回来点「续费」→ 选 1 个月 → 确认
```

**就这 4 步。** 卡片上那个数字变了，就说明有人快到期了 —— 不用记任何日期。

### 第一次用：把你手上的包月客户录进去

```
「客户」→ 右上角「+ 新增客户」，填 5 样就够：
   客户称呼  ：微信昵称就行（例如 小明）        ← 只有这个是必填的
   联系方式  ：微信号 / QQ / 闲鱼号
   服务/分区 ：下拉选（例如 明日方舟）
   买的档位  ：自由文本（例如 精托托管）
   金额      ：自由文本（例如 20R/月）         ← 你怎么写就怎么显示，不会自动加 ¥
   开始日期  ：选一下
   到期日期  ：★ 就是那天要提醒你的日子
   备注      ：账号情况、返图时间…（选填）
```

> **到期日期留空 = 一次性 / 长期**，这种客户永远不会出现在催续费清单里。
> 陪玩散单、剪辑项目就不用填日期，录个档方便以后查。

**更快的办法**：客户在网站上自助预约过之后，去「预约与时间」找到那条记录，
右边有个 **「存为客户」** 按钮 —— 点它，**称呼、联系方式、渠道已经帮你填好了**，
你只要补上档位和到期日就行。

### 客户列表怎么用

| 你想干什么 | 怎么做 |
|---|---|
| 只看这几天要催的 | 点顶部卡片，或点筛选按钮「待催（超期+7天内）」 |
| 找某个客户 | 右上角搜索框，输称呼 / 联系方式 / 档位都能搜到 |
| 看某个人还剩几天 | 「剩余」那一列就是彩色徽章：`已超期 2 天` / `今天到期` / `还有 2 天` / `长期` |
| 客户续了 | 点那一行的「续费」 |
| 客户不做了 | 点「编辑」→ 状态改成「已结束」（记录留着，以后好查账） |
| 录错了 | 点「删除」（**只删这条档案，预约记录和展示墙一条都不动**） |

### 「续费」弹窗里那个「从哪天算」，怎么选

```
续多久    ：1 个月 / 3 个月 / 1 周 / 自定义天数
从哪天算  ：从原到期日往后推（推荐）  ← 客户还在服务期里，选这个，不损失他付过的天数
            从今天算              ← 他停了一阵子、现在重新开始，选这个
```

弹窗里会实时显示 `当前：8月20日 到期 → 续费后：9月20日 到期`，**看得见再点确认**。

> ⚠️ **已经超期很久的客户**：如果选"从原到期日往后推"，算出来的新到期日**可能还是过去的日期**
> （比如他 2 月就到期了，现在都 6 月了，续 1 个月 = 3 月）。
> 这时候后台会弹一句提示，让你改用「从今天算」——
> 因为"补上那段空窗"通常不是你想要的。

### 复制出来的话术长这样（想改口气就改一处）

```
老板，你的明日方舟 精托托管 8月20日到期啦（还有 2 天），要续吗？
续的话还是 20R/月，跟我说一声就行～
```

- 已经超期的会自动变成「已经到期 2 天啦」（不会催得像没事一样）；
- 没填档位就不提档位，没填金额就不提价格（免得客户以为你要涨价）；
- 连服务都没填时会写成「你的服务 …」，不会留一个空荡荡的"你的"；
- 没有到期日的（长期/一次性）会换成问候口气，不硬说"到期"；
- **模板只有一处**：`static/admin.js` 里的 `renewMessage()`，函数上面写了怎么改。

### 两个必须知道的坑

1. **"今天"一律按北京时间算**（`today_cn()`），不受服务器时区影响 ——
   否则服务器在 UTC 时，北京时间早上 8 点前都会算成"昨天"，该催的那天就不催了；
2. **金额是自由文本**：`20R/月`、`推图15R`、`100R/月（含月卡5R）` 你写什么就是什么，
   系统**永远不会**自动加 `¥` 或转成数字。这一条有 6 条自动测试守着。

> 客户档案**会跟着备份一起导出、一起恢复**；
> 而且**老备份**（还没有客户档案那一版导出的）也能正常导入 ——
> 它不会清空你现在的客户，只是跳过客户那一步。

## 七之四、★ 展示墙：怎么把视频和网站挂上去（剪辑 / PS / 建站的单子靠它）

### 为什么要有「外链」

陪玩的作品是**截图**，看一眼就够了。但剪辑的作品是**视频**（在 B 站）、
建站的作品是**一个网址** —— 光传一张封面图，客户看不到成品，凭什么下单？

所以展示墙的每一项都能挂一个链接：**客户点那张图，直接新窗口打开你的作品**。

### 怎么传（30 秒）

```
① 后台 →「展示墙」→ 上面「新增展示」那块
② 先选「这张图属于哪个分区」 → 选你的剪辑/建站分区
③ 分类：选「作品」（默认就有这一类；没有就自己加，见下）
④ 点开跳转的链接：填完整地址 ——  https://www.bilibili.com/video/BV…
                               https://你做的网站.com
⑤ 传一张封面图（B 站视频可以直接截一帧）→ 勾「立即公开」→ 点「保存到展示墙」
```

**客户看到什么**：那张图右上角会出现一个小角标 **「点开看 ↗」**，
点一下 = 新窗口打开你的视频 / 网站。**没有填链接的图，点一下还是放大看图**（老行为不变）。

> ⚠️ 链接**必须以 `http://` 或 `https://` 开头**，比如 `https://…`。
> 直接粘 `www.bilibili.com/xxx`（少了 `https://`）会被忽略 —— 那不是没保存，
> 是系统故意不认（写别的东西比如 `javascript:` 会有安全风险，所以只认标准网址）。

### 想改那个角标上的字（「点开看 ↗」）

就一处：`static/zone.js` 里的 `GALLERY_LINK_BADGE`。想改成「看视频 ↗」「看我做的站 ↗」
都行，改完强制刷新（Ctrl + F5）就生效。**所有带链接的图共用这一句话**，
做不到"这张写看视频、那张写看网站"。

### 改已经传上去的那一项

列表里每一项右边有个 **「编辑」** → 展开一小块，能改**分类**和**链接**
（链接清空 = 取消外链，那张图就变回"点开放大"）。改完点「保存这项」。

### ★ 展示墙的分类可以自己加

默认三类：**游戏截图 / 老板评价 / 作品**。想再加（比如「剪辑作品」「建站作品」「PS 修图」）：

```
后台 →「展示墙」→「分类管理」那一块：
   · 改名      ：直接改输入框里的字 → 点「保存」
   · 调顺序    ：↑ ↓（顺序 = 客户看到的筛选按钮顺序）
   · 新增      ：下面填个名字 → 点「+ 新增分类」
   · 删除      ：点「🗑 删除」
```

三条规矩（都是故意的）：

1. **短标识（id）不能改** —— 已经传上去的图是靠 id 认分类的，改了那些图就对不上号了。
   改名字随便改，客户看到的就是名字；
2. **分类下面还有图的时候删不掉** —— 会提示你"还有 N 张图在用"。请先把那几张图
   用「编辑」改到别的分类，或者删掉/归档，再回来删这个分类。
   **为什么不自动帮你把图搬走**：那会悄悄改变客户看到的分组（比如把"作品"混进"游戏截图"），
   而你根本不会发现。宁可让你多点几下，每一步都看得见；
3. **至少要留一个分类**。

> 新分类建好之后，客户在前台看到的筛选按钮会自动多一个（刷新页面即可）。

## 七之五、★ 客户自助预约要「确认」一下才踏实（每天顺手看一眼）

### 为什么要多这一步

客户在你网站上点「立即锁定时间」，**那几格立刻就被锁走了**（这是你要的：先到先得、占住再说）。
但"占住"不等于"这单成立"：万一他没加微信、联系不上，那段时间就**白白占着**——
而时段就是你的库存，库存就是钱。

所以现在客户自助预约进来时会先算 **「待确认」**：
时间照样锁住（别的客户约不到），但会挂在你后台最上面，直到你处理它。

### 每天怎么处理（10 秒）

```
① 打开后台 → 看最上面 ——「预约与时间」页最顶上是橙红色边框的「待确认的预约」
   （标签栏上面那条「📌 今天：… · N 单待确认」点一下也会带你过来）
② 每一行写着一句话：
   小明 · 微信 wx_xiaoming · 三角洲行动 · 机密·零号大坝 · 10月15日 20:00–22:00 · 2小时 ¥30 · 已经等了 3 小时
③ 看着办，两个按钮二选一：
   ✅「已确认」  → 加得上微信、谈得拢，这单就这样了
   🗑「释放时段」→ 联系不上 / 他放你鸽子，把这几个小时还给别人
```

- 一条都没有时，那块会显示 **`没有待确认的预约 ✓`**；
- 已经结束的单（时间过去了）不会再挂在上面 —— 已经打过的单不该再来烦你；
- **点「释放时段」之前会弹一句确认**，因为删了就回不来了：
  > 释放后这段时间会重新开放预约，别人可以约走。确定吗？
  > （客户那边不会收到通知，建议先微信问一句）

> 想取消一条**已经确认过**的预约？去下面的时段列表找那条，点右边的「取消」——
> 那才是"取消一个已经成立的预约"。待确认区那两个按钮只处理"还没认领"的单。

### 想让它自动处理？（★ 默认是关的，推荐先用 0）

待确认那块下面有一行小设置：

```
待确认超过 [ 0 ] 小时自动释放（0 = 不自动，推荐先用 0）   [保存]
```

- **填 0 = 关闭**（默认就是这个）。**什么都不会被删**；
- 填个数字（比如 `24`）之后：客户自助预约**超过 24 小时还没被你确认**，系统会自动把它释放掉，
  那段时间回到可约。**客户不会收到通知**，所以别设得太短；
- 下面会显示 **「最近自动释放」**，比如：
  > · 小明 10月15日 20:00（超过 24 小时没确认）

**四条安全线**（任何一条不满足都不删，这是"会删数据"的功能，我写得很保守）：

1. **只删客户自助预约** —— 你自己在后台锁的时段，等多久都不会被自动删；
2. **只删你还没确认过的** —— 点过「已确认」的一律不碰；
3. **只删还没开始的时间** —— 已经开始或已经过去的绝不碰（人家昨天真的打过了，
   那单不能因为"你没点确认"就被抹掉）；
4. 算不出下单时间的老数据不参与。

> ⏰ **它是"下次有人访问网站时才生效"，不是掐着秒表执行的**：
> 这个站跑在免费托管上，没有常驻的定时任务。所以是"有人打开网站或后台"的那一刻顺手检查一遍。
> 换句话说：**你打开后台看到它还没被释放，刷新一下就对了**。

> 建议的用法：**头两周先用 0（关着）**，每天开后台看一眼待确认区，
> 你很快就会知道自己该不该开、开几小时合适（比如你只在晚上接单，那 12 小时可能就够）。

## 七之六、★ 怎么看收入（钱从哪来、该推什么）

> **这一节回答两个问题**：这个月赚了多少？**哪个服务最来钱、哪个客户最舍得？**
>
> 你每天都知道自己收了多少钱（微信里有记录），但月底想"我是不是该多推代肝、
> 少接点散单"的时候，光靠印象是答不上来的。所以后台多了一个「收入」标签页，
> 它会把每一笔钱记下来，然后替你算。

### 最重要的一件事：**你不用专门记账**

这个页面是围着一句话设计的：**登记必须发生在他本来就要做的动作里**。
所以三个入口全都挂在你已经在做的事情上：

| 什么时候 | 会发生什么 | 你要多做一步吗 |
|---|---|---|
| 客户自助预约，你点**「已确认」** | 自动记一笔（金额 = 这单的价格，日期 = **这单开始那天**） | **不用**，你本来就要点确认 |
| 客户**续费**时 | 续费弹窗里多了一个金额框，**默认已经帮你填好了**（`100R/月` → 100） | 顶多点一下确认 |
| 剪辑 / PS / 建站的**一次性单子** | 收入页右上角点「+ 记一笔」补上 | 要动手（这种单子不在时间表里，没有"确认"这一步） |

**你不需要每天记账。** 只有第三种（时间表外的单子）需要你手动补一下 —— 一单 10 秒。

### 「收入」页上那几块东西怎么看

```
① 大字         本月收入 ¥1,240
                比上月 +18%        ← 上月一笔都没有时会写"上月没有记录"（不会骗你说 0%）

② 时间范围      [本月] [上月] [近 3 个月] [今年] [全部]   ← 点一下切换，下面全都跟着变

③ 按大类小卡    🎮 陪玩 ¥480（12 笔）  ⚡ 代肝 ¥600（6 笔）  🎨 其他服务 ¥160（1 笔）
                （没挂在任何分区上的记录会归到「未分类」—— 那不是错误，
                  说明你有单子没挂到分区上，剪辑这类一次性单子多半就在那儿）

④ 两个排行      哪个服务最来钱：三角洲行动 ¥480 · 明日方舟 ¥600 · 视频剪辑 ¥160
                哪个客户最舍得：小明 ¥300 · 阿伟 ¥200 · …

⑤ 流水明细      一行一笔：日期 · 服务/项目 · 客户 · 金额 · 来源（确认预约/续费/手动补记）· 改/删
                最多显示 100 条，多了会在下面写一句"只显示最近 100 条"
```

**「今天待办条」上没有收入数字，这是故意的** —— 那是"今天要干什么"，不是"赚了多少"。
钱的事只在「收入」这一页看，两件事不混在一起。

### 每周看一眼（3 分钟，周日晚上顺手做）

1. 后台 →「收入」→ 看**大字**：这个月比上个月是涨了还是跌了；
2. 点「上月」「近 3 个月」各看一眼，**看趋势不看单月**（这个月少接几单不代表生意差了）；
3. 看**两个排行**，问自己一句：
   - 「哪个服务最来钱」排前面的，**下个月多推它**（多传几张它的展示墙、朋友圈多发一条）；
   - 排最后的，是不是该少花点心思；
   - 「哪个客户最舍得」里的那几个，**值得多维护**（他续费的时候你多问一句、返图快一点）；
4. 发现"未分类"的钱不少 → 说明有很多单子没挂在分区上，
   在「记一笔」的时候顺手选一下「服务」，下个月排行就准了。

> 别的都不用管。**这一页的全部价值就是让你知道钱从哪来、该推什么。**

### 几个"故意这么设计"的地方（别以为是 bug）

| 现象 | 为什么 |
|---|---|
| 同一单点了两次「已确认」，收入只多了一笔 | 故意的（**防重复记账**：同一个单据只记一次）。恢复备份之后重放也不会多记 |
| 客户自己锁的、你手动锁的时段，确认后**没有**记收入 | 只有客户自助预约（`source=client`）才有「已确认」这一步；而且 **价格是 0 的一律不记**（免得流水里一堆 ¥0 把统计搞浑） |
| 免费补偿的单子（¥0）没进流水 | 同上：0 元的记录只会让统计变脏，一点信息量都没有 |
| 续费的时候不填金额，就什么都没记 | 故意的：**不逼你填**（很多单是先续后收钱）。金额框默认已经帮你填好了，改一下就行 |
| 收入页的日期按「这单开始那天」算，不是「你点确认那天」 | 打完之后才点确认是常态，按开始那天算，这笔钱才会落在"这单真正发生"的那个月里 |
| 手动补记时日期打错了，它也记上了 | 它按**今天**记，并在下面提示一句"日期没填或格式不对，我按今天记上了"。宁可记成今天让你改一下，也不打回整张表单让你重填 |
| 本月/上月的边界是**自然月**（1 号到最后一天），而且是**北京时间** | 你想的是"这个月比上个月"，不是"最近 30 天比前 30 天"；北京时间是为了和客户到期提醒口径一致 |

> **收入流水会跟着备份一起导出、一起恢复** ——
> 而且**老备份**（还没有收入这一版导出的）也能正常导入，
> 它不会清空你现在记的账，只是跳过收入那一步。

## 八、排错

| 现象 | 原因 / 解决 |
|---|---|
| `python app.py` 报 `Address already in use` | 8123 端口被占了：`set PORT=9000 && python app.py` |
| 打开主页一片空白 | 按 F12 看 Console 报错；多半是 `data/` 没写权限 |
| 后台登录后一直跳回登录页 | 浏览器禁用了 Cookie；换浏览器或关掉无痕模式 |
| 客户说"看到的时间是灰色的点不动" | 那格子是 `rest`（休息）或 `past`（已过去），正常 |
| 客户说"点预约提示时间被抢了" | 那几格真的刚被别人锁了（409），让他重新选即可 |
| 客户说"提交太频繁" | 同一个 IP 10 分钟内提交超过 5 次（429），等几分钟再来 |
| 客户说"这个分区不支持时段预约" | 它是服务制分区（代肝/剪辑…）：包干项目本来就没有时间表 |
| `/z/xxx` 打开是 404 | 分区被**删除**了（不是隐藏）。隐藏的分区页仍然能打开 |
| **收不到预约通知** | 后台「安全与备份 → 预约通知」看上次结果；`HTTP 403` 多半是 token 错，`超时` 多半是服务器连不上外网 |
| **展示墙上传了外链，但客户点图还是放大** | 链接不是 `http://` 或 `https://` 开头（少了 `https://` 也会不算）。去列表里点「编辑」补全 |
| **想删展示墙的某个分类，删不掉** | 那类下面还有图。提示里会写还有几张，用「编辑」把它们改到别的分类再删 |
| **待确认的单一直挂在那儿** | 就是要让你看见。点「已确认」或「释放时段」；想自动处理就开自动释放（建议先用 0） |
| **开了自动释放，到点了却没删** | 它是**下次有人访问网站时才生效**（没有常驻定时任务）：刷新一下后台页面即可 |
| **客户自助预约不见了** | 看后台「最近自动释放」那一行 —— 是不是开了自动释放、而且超过了设定的小时数 |
| 改了 `app.py` 没生效 | 需要重启服务（`Ctrl+C` 后重新 `python app.py`） |
| 网页样式错乱 | 强制刷新：`Ctrl + F5` |

## 怎么改成别的游戏（不用改代码）

这套代码**不绑定任何游戏**。想再开一个游戏的分区，就是在「分区管理」里新建一个分区：

| 想改什么 | 去哪里改 | 例子 |
|---|---|---|
| **加一个游戏/服务** | 后台 →「分区管理」→「+ 新增分区」 | 新增 `naraka` → 永劫无间 |
| **游戏名 / 服务名** | 后台 →「资料与报价」→ 顶部选分区 → **游戏名** | `三角洲行动` → `永劫无间` |
| 接单平台 | 同上 → **接单平台** | `PC 电脑端` / `手游` |
| 标语、大标题、简介 | 同上 | 每个分区一套，互不影响 |
| 报价档位（陪玩类） | 同上 →「陪玩报价」→ 名称 / 说明 / 每小时价格 | 想加档就点「+ 增加一档」 |
| 价目表（代肝/剪辑类） | 同上 →「价目表（分组）」→ 📋 批量粘贴导入 | 一行 `名称 | 价格 | 说明` |
| 打法标签 | 同上 → **服务亮点 / 打法标签** | 用中文逗号隔开 |
| 服务承诺 | 同上 →「服务承诺 / 服务说明」 | 每行一条 |
| 分区背景图/首屏图/分享图/主色 | 同上 →「分区图片」 | 每个分区独立一套 |
| 老板评价 / 截图 / 作品 | 后台 →「展示墙」→ 先选分区 | 分类选「游戏截图」「老板评价」或「作品」（分类可以自己加） |
| 剪辑视频 / 建站作品的链接 | 同上 →「点开跳转的链接（选填）」 | 填 `https://` 开头的完整地址，客户点图就跳过去 |
| 全局的品牌名/昵称/微信号/信任信号 | 后台 →「资料与报价」→ 最下面「全局资料」 | 所有分区共用 |

**改完点「保存这个分区」，那个分区页立刻生效**（不用重新部署）。

客户生成的预约文案会自动跟着变（游戏名来自**分区**的资料）：

```
分区 game=永劫无间 平台=PC 电脑端  →  你好，XX！想约永劫无间 PC 电脑端陪玩。
分区 game=永劫无间 平台留空        →  你好，XX！想约永劫无间陪玩。
分区 game 留空（全局填了就用全局）  →  你好，XX！想约<全局游戏名> PC 电脑端陪玩。
哪都没填                           →  你好，XX！我想约你的陪玩服务。
```

## 想用它开第二个站？（10 分钟）

> 现在一般**不需要**开第二个站了：一个站就能挂陪玩 / 代肝 / 剪辑任意多个分区。
> 只有"想给完全不同的账号/品牌做一套独立网站"时才需要下面这些步骤。

```text
① GitHub 上把这个仓库复制一份
   仓库页 → Settings → 最下面 Danger Zone →「Template repository」勾上
   以后点「Use this template」就能一键生成新仓库（或者直接 Fork）

② 新仓库按 DEPLOY-PYTHONANYWHERE.md 部署一遍
   （注册新 PythonAnywhere 账号 → git clone → 建 Web App → 写 WSGI 文件 → Reload）

③ 进新站后台：改全局资料 + 在「分区管理」里删掉/改掉示例分区，建自己的

④ 换管理密码（后台 →「安全与备份」→ 修改管理密码）

⑤ 配预约通知（后台 →「安全与备份」→「预约通知」→ 填 PushPlus token）

⑥ 把新网址发给客户 —— 完成
```

> ⚠️ 每个站要**单独设密码和通知 token**，别几个站共用一套。
